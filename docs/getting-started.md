# Getting started with Tether

Tether keeps your Markdown and the conversation about it together in one view.

1. **Try a comment.** Highlight the sentence below, then choose Comment and ask your agent a question.

   What would you like to build next?

2. **Ask your agent to respond.** Copy this into your coding-agent conversation:

   > Review my comments in Tether on `{{DOCUMENT_PATH}}` and reply in the threads.

   A comment waits for you to ask; it does not automatically run an agent. If your agent needs the review instructions, run `tether setup --help` for setup options.

3. **Finish the exchange.** Read the reply, add another comment if needed, then resolve the thread when you're done.
4. **Bring your own file.** Open Folio, choose Add Markdown files, and select a document. You can edit its text in the reader and save with ⌘S.
5. **Come back later.** Run `tether` or double-click Open Tether to reopen Folio. Archived documents stay available until you choose to remove their conversations or enable expiry.

Your Markdown stays in its original file. Comments are private local data and aren't included when you share that file. Use **Export with annotations** to share its open conversations in a `.tether` package.
